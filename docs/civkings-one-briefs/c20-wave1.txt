  PLAYS ON. A century is saved at three points. For each, a second process loads the save and plays the turns that remain. The game it ends with must be the same game the uninterrupted century ends with.
  CHAIN RULINGS. The three chain petitions (kinds chain:war_price, chain:general_strike, chain:heir_break) offer two rulings each. For each of the six, a game is played until the petition is on a docket, saved, loaded by a second process and ruled there through gilded.docket.rule, and three more turns are played. The world must then be the same game BASE reaches when the same ruling is made at the same turn in a game that was never saved.

  A NEW GAME. civkings.session.new_game(seed, house=None) returns (game, house). game is the simulation's own GildedGame for that seed - the world GildedGame(seed, None) builds. house is the name of the player House: the one asked for, or the first by name when none is asked for. Exactly one House has is_player set, and it is that one. A name that is no House raises ValueError.
  THE SMOKE RUN. "python -m civkings --smoke --turns N --seed S" (and optionally --house NAME) plays N turns headless. After each turn it saves the game and has ANOTHER Python process load that save and agree with it. It exits 0 only if every one of the N saves was read back that way; when a save cannot be read back by the second process it exits non-zero.
